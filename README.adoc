= USB UPS Simulator for Arduino Leonardo + W5500

A USB HID UPS simulator for NUT/Nut-ups testing.

The reference firmware runs on an Arduino Leonardo/ATmega32U4 and presents a USB HID Power Device to the system under test. A W5500 Ethernet shield provides a separate TCP control channel so test software can inject mains failure, battery charge/runtime, load, input/output voltage, low-battery, overload, replacement-battery, and shutdown conditions without disturbing the USB connection.

Hardware UART (`Serial1`) provides a fallback control path using the same protocol.

== Architecture

[source,text]
----
                  management / test network
                          TCP 5000
                             |
                             v
                    +----------------+
                    | W5500 Ethernet |
                    +-------+--------+
                            |
                         SPI/ICSP
                            |
                    +-------+--------+
                    | Arduino        |
                    | Leonardo       |
                    +---+--------+---+
                        |        |
                 USB HID UPS   Serial1
                        |       115200
                        v
                 NUT host under test
----

The USB connection is the simulated UPS interface. Ethernet/UART are the simulator control interfaces.

== Key features

* USB HID Power Device / UPS based on the HIDPowerDevice library
* upstream NUT `usbhid-ups` Arduino HID compatibility
* W5500 Ethernet control on TCP port `5000`
* `Serial1` UART control at `115200`
* DHCP with `169.254.42.42/16` fallback
* explicit `ARM ON` safety gate before state-changing commands
* `RESET` / `ARM OFF` safe-state recovery
* non-blocking firmware loop
* Python API and `ups-sim` CLI
* NUT-facing battery, runtime, voltage, load, input/output voltage and delay fields
* automated Arduino and Python CI

== Supported reference hardware

* Arduino Leonardo or compatible ATmega32U4 native-USB board
* W5500 Ethernet shield with the 2x3 ICSP connector populated

On Leonardo, SPI is taken from the ICSP header. Common UNO-style W5500 shields that do not connect to the ICSP header are not directly compatible.

Standard shield usage:

[cols="1,1,3",options="header"]
|===
|Function |Connection |Notes

|W5500 SPI
|ICSP
|MOSI/MISO/SCK

|W5500 CS
|D10
|Reserved for Ethernet

|microSD CS
|D4
|Firmware keeps HIGH; leave SD unused for commissioning

|UART
|D0/D1
|`Serial1`, 115200 baud

|USB HID UPS
|Leonardo USB
|Connect to NUT/system-under-test host
|===

== Quick start

=== 1. Clone into the Arduino library directory

[source,shell]
----
mkdir -p ~/Arduino/libraries
cd ~/Arduino/libraries
git clone https://github.com/ami3go/USB-UPS-Simulator.git HIDPowerDevice
cd HIDPowerDevice
git switch main
----

=== 2. Install Arduino dependencies

[source,shell]
----
arduino-cli core update-index
arduino-cli core install arduino:avr
arduino-cli lib install Ethernet
----

=== 3. Compile

[source,shell]
----
arduino-cli compile \
  --fqbn arduino:avr:leonardo \
  ~/Arduino/libraries/HIDPowerDevice/examples/UPS_Simulator_Ethernet
----

=== 4. Upload

[source,shell]
----
arduino-cli board list
arduino-cli upload \
  --fqbn arduino:avr:leonardo \
  -p /dev/ttyACM0 \
  ~/Arduino/libraries/HIDPowerDevice/examples/UPS_Simulator_Ethernet
----

Replace `/dev/ttyACM0` with the actual Leonardo port. Arduino IDE 2.x is also supported; see the flashing guide.

=== 5. Connect over Ethernet

The firmware requests DHCP first. If DHCP fails it falls back to:

[source,text]
----
169.254.42.42/16
TCP 5000
----

Connect:

[source,shell]
----
nc <simulator-ip> 5000
----

A new connection reports that the simulator is disarmed.

=== 6. Run a safe first test

[source,text]
----
PING
STATUS?
ARM ON
AC OFF
BATTERY 40
LOAD 65
INPUTVOLTAGE 22850
OUTPUTVOLTAGE 23010
STATUS?
RESET
----

Voltage values in the wire protocol are centivolts (`23000` = 230.00 V).

== Python control driver

Install from the repository:

[source,shell]
----
python -m pip install -e ./python-driver
----

For UART support:

[source,shell]
----
python -m pip install -e './python-driver[serial]'
----

Example:

[source,python]
----
from ups_simulator import UpsSimulator

with UpsSimulator.tcp("192.168.1.50") as ups:
    with ups.armed_session():
        ups.set_ac(False)
        ups.set_battery(40)
        ups.set_load(65)
        ups.set_input_voltage(228.5)
        ups.set_output_voltage(230.1)
        ups.set_runtime(300)
        print(ups.status())
----

`armed_session()` sends `RESET` on exit, including exception paths.

CLI example:

[source,shell]
----
ups-sim --host 192.168.1.50 status
ups-sim --host 192.168.1.50 arm
ups-sim --host 192.168.1.50 ac off
ups-sim --host 192.168.1.50 battery 40
ups-sim --host 192.168.1.50 load 65
ups-sim --host 192.168.1.50 input-voltage 228.5
ups-sim --host 192.168.1.50 output-voltage 230.1
ups-sim --host 192.168.1.50 reset
----

----

----

== Safety

The simulator can generate conditions that make NUT shut down real systems.

* firmware starts disarmed
* state-changing commands require `ARM ON`
* `RESET` and `ARM OFF` restore the safe online state
* TCP/5000 has no authentication or encryption
* do not expose the control port to an untrusted network
* validate shutdown behavior on a test host before connecting production NAS/servers

`ARM ON` is a safety guard, not authentication.

== Full-cycle shutdown testing

If the NUT host is expected to power down, power the Leonardo independently through a supported external-power input so that the W5500 remains reachable while the host is off. Keep USB connected so the host sees the HID UPS whenever it is powered.

See `docs/HARDWARE.md` for details.

== Resource limit

Reference CI build:

[source,text]
----
Original UPS example:
  flash  9818 / 28672 bytes (34%)
  RAM     302 / 2560 bytes (11%)

Ethernet/NUT simulator:
  flash 28070 / 28672 bytes (97%)
  RAM    1296 / 2560 bytes (50%)
----

Only about 602 bytes of flash headroom remain. The Leonardo firmware should be treated as effectively feature-frozen. Scenario engines, logging, configuration storage, authentication, web/Cockpit UI, retries and orchestration belong in the Python/Linux side.

== Original HID UPS example

The repository retains the original minimal example in:

[source,text]
----
examples/UPS/UPS.ino
----

The NUT-specific descriptor extension is instantiated only by the Ethernet simulator so the original example remains minimal.
